Model Pangkalan Data Relational Normal (3NF)

Struktur Column & Database Schema

Reka bentuk jadual relational pangkalan data (Relational Schema) bagi menyimpan maklumat resume eksekutif ini secara dinamik, normalized, dan fleksibel untuk menyokong aplikasi berskala enterprise.

1. Table: profiles (Profil Utama Pengguna) Primary Entity
Column Name Data Type Key / Constraint Penerangan / Kegunaan
id BIGINT PK, AUTO_INC ID Unik Profil
full_name VARCHAR(150) NOT NULL Nama Penuh Pemohon bersama gelaran
job_title VARCHAR(150) NOT NULL Gelaran Jawatan Eksekutif Utama
executive_summary TEXT NULLABLE Ringkasan profil profesional lengkap
email VARCHAR(100) UNIQUE, NOT NULL Alamat Emel Perhubungan Rasmi
phone VARCHAR(30) NOT NULL Nombor Telefon Bimbit / Pejabat
location VARCHAR(100) NOT NULL Bandar & Negara Kediaman
linkedin_url VARCHAR(255) NULLABLE Pautan Profil LinkedIn
website_url VARCHAR(255) NULLABLE Pautan Portfoli / Laman Web Rasmi
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP Tarikh Rekod Dicipta
2. Table: experiences (Pengalaman Kerja) 1-to-Many Relationship
Column Name Data Type Key / Constraint Penerangan / Kegunaan
id BIGINT PK, AUTO_INC ID Unik Pengalaman Kerja
profile_id BIGINT FK (profiles.id) Rujukan Foreign Key ke Jadual Profiles
job_title VARCHAR(150) NOT NULL Gelaran Jawatan Disandang
company_name VARCHAR(150) NOT NULL Nama Syarikat / Organisasi
location VARCHAR(100) NULLABLE Lokasi Syarikat Bertapak
start_date DATE NOT NULL Tarikh Mula Berkhidmat
end_date DATE NULLABLE Tarikh Tamat (NULL jika masih bekerja)
is_current BOOLEAN DEFAULT FALSE Penanda (1/0) bagi jawatan semasa
achievements_json JSON NULLABLE Senarai bullet points pencapaian (Stored as JSON Array)
3. Table: educations (Kelayakan Akademik) 1-to-Many Relationship
Column Name Data Type Key / Constraint Penerangan / Kegunaan
id BIGINT PK, AUTO_INC ID Unik Rekod Pendidikan
profile_id BIGINT FK (profiles.id) Rujukan Foreign Key ke Profiles
degree_name VARCHAR(150) NOT NULL Nama Ijazah / Sijil Academic
institution VARCHAR(150) NOT NULL Nama Universiti / Institusi Pendidikan
start_year INT NOT NULL Tahun Mula Pengajian
end_year INT NULLABLE Tahun Tamat Pengajian
grade_description VARCHAR(100) NULLABLE CGPA / Anugerah Canselor / Kelas Pertama
4. Table: certifications

id: BIGINT (PK)

profile_id: BIGINT (FK)

cert_name: VARCHAR(150)

issuing_body: VARCHAR(150)

issue_year: INT

expiry_year: INT (Nullable)

5. Table: skills

id: BIGINT (PK)

profile_id: BIGINT (FK)

category: VARCHAR(50) (e.g. Leadership, DevOps)

skill_name: VARCHAR(100)

proficiency_level: VARCHAR(30) (e.g. Expert)
